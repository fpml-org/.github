# Welcome to the FpML.org GitHub Repository

FpML® (Financial products Markup Language) is an open, XML‑based industry standard for representing and exchanging data for OTC derivatives and structured products. Sponsored by ISDA and developed as a true open standard, FpML enables consistent, interoperable processing of financial transactions across the derivatives lifecycle, independent of underlying systems or infrastructure.
